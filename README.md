# Лабораторні роботи з курсу «Інтерфейси користувача»

Чотири вебзастосунки з нетрадиційними інтерфейсами: голос, жести, доповнена й віртуальна реальність. Кожна лабораторна — окремий проєкт на Node.js зі своїм сервером, тестами й звітом.

| № | Тема | Папка | Порт | Технології |
|---|---|---|---|---|
| 1 | Голосовий інтерфейс для управління базою даних працівників | [lab1-voice-db](lab1-voice-db/) | 3000 | Web Speech API, Express, SQLite |
| 2 | Жестовий інтерфейс для управління базою даних працівників | [lab2-gesture-db](lab2-gesture-db/) | 3001 | MediaPipe Gesture Recognizer, Express, SQLite |
| 3 | AR-рулетка: вимірювання в доповненій реальності | [lab3-ar-measure](lab3-ar-measure/) | 3002 | three.js, WebXR (ARCore), симулятор AR |
| 4 | Віртуальне 3D-меню ресторану в AR/VR | [lab4-vr-menu](lab4-vr-menu/) | 3003 | three.js, WebXR, MediaPipe (рука, очі), Web Speech API |

## Вимоги

- **Node.js 22.13 або новіший** (використовується вбудований модуль `node:sqlite`);
- **Google Chrome** або Microsoft Edge (розпізнавання мовлення, камера, WebXR);
- для лаб. 2 і 4 — вебкамера, для лаб. 1 і 4 — мікрофон.

## Запуск

Кожна лабораторна запускається окремо зі своєї папки:

```bash
cd lab1-voice-db
npm install
npm start
```

Потім відкрийте в браузері адресу з таблиці (наприклад, http://localhost:3000). У лаб. 2 і 4 `npm install` також завантажує моделі MediaPipe (8–12 МБ), далі застосунок працює без інтернету.

База даних SQLite створюється в папці `data/` під час першого запуску.

## Тести

```bash
npm test           # модульні тести (у всіх лабораторних)
npm run test:e2e   # браузерні перевірки в Chrome без вікна (лаб. 2–4)
```
