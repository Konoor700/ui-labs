# Лабораторна робота №3. AR-рулетка: інтерфейс доповненої реальності для вимірювань

Вебзастосунок для вимірювання відстаней, периметрів і площ у просторі за допомогою доповненої реальності. Ви ставите віртуальні точки на знайдені поверхні (стіни, підлогу, стіл). Застосунок з’єднує їх лініями й показує довжини прямо в просторі: «113,0 + 77,8 + 126,5 = 317,3 см». Виміри зберігаються в базі.

Є два режими:
- **Симулятор** — основний, працює на звичайному комп’ютері. Замість камери телефона ви рухаєтеся віртуальною кімнатою з відомими розмірами (двері, вікно, стіл), а застосунок відтворює поведінку ARCore: поступове знаходження площин, «hit-test», похибку трекінгу, вплив освітлення.
- **Справжній AR** — у Chrome на Android-телефоні з ARCore, через WebXR. Кнопка «Почати AR» з’являється автоматично, якщо пристрій підтримує AR.

## Запуск

```bash
npm install
npm start          # http://localhost:3002
npm test           # модульні тести
npm run test:e2e   # браузерні перевірки (Chrome без вікна й без звуку)
```

Відкрийте http://localhost:3002 у Chrome. Під час першого запуску з’явиться довідка з керуванням.

## Керування в симуляторі

| Дія | Як |
|---|---|
| Рухатися / повертати | W A S D, стрілки |
| Оглядатися | затиснути ліву кнопку миші й тягнути |
| Вгору / вниз, вперед / назад | R / F, колесо миші |
| Поставити точку там, де клікнули | клік по поверхні |
| Поставити точку в місці прицілу | Пробіл або кнопка «+» |
| Видалити останню точку | Backspace або кнопка ⌫ (ліворуч від олівця) |
| Видалити вибрану точку | Delete |
| Скасувати дію | Ctrl+Z |
| Замкнути / розімкнути контур | C |

Як виміряти:
1. Повільно оглядайте кімнату. Знайдена поверхня вкривається кольоровою сіткою (як в ARCore) і поступово «розростається» туди, куди ви дивитеся.
2. Наведіть приціл на край об’єкта й поставте точку. Від останньої точки до прицілу тягнеться пунктир із поточною відстанню.
3. Ставте наступні точки: довжини відрізків і сума з’являються в просторі та в рядку «РЕЗУЛЬТАТ».
4. **Прилипання:** якщо навести приціл ближче 6 см до наявної точки, приціл стає помаранчевим і нова точка ставиться точно в неї. Біля першої точки (коли точок 3 і більше) це замикає контур: з’являються периметр і площа. Вимикається перемикачем «Прилипання».
5. Меню (кнопка-олівець): видалити точку, змінити порядок, замкнути контур (периметр і площа), скасувати, очистити, зберегти, перевірити точність.

## Функції

- Пошук поверхонь з візуалізацією: сітка знайдених площин і «характерні точки» трекінгу.
- Приціл, що лягає на поверхню за її нормаллю; прев’ю лінії до прицілу з відстанню.
- Точки, лінії й підписи відстаней у 3D; ламана з кількох відрізків; замкнений контур з периметром і площею (якщо точки в одній площині).
- Прилипання точок (6 см): точне з’єднання ліній і автоматичне замикання контуру біля першої точки.
- Віртуальне меню: видалення, зміна порядку, скасування (Ctrl+Z), очищення; окрема кнопка й клавіша Backspace для видалення останньої точки.
- Одиниці — см або м; формат українською («317,3 см»).
- Збереження вимірів у SQLite, список збережених, відкриття, видалення.
- **Перевірка точності**: розміри об’єктів кімнати відомі (двері 90 × 210 см, вікно 120 × 140 см, стіл 120 × 70 × 75 см, кімната 5 × 4 × 2,7 м), тож вимір порівнюється з еталоном. Таблицю перевірок можна скопіювати для звіту.
- Умови: освітлення (нормальне / тьмяне / темно), похибка трекінгу (вмик./вимк.), показ площин.

## Обґрунтування вибору технологій

| Компонент | Вибір | Чому |
|---|---|---|
| Платформа | **Веб** | Працює без встановлення на комп’ютері й телефоні; той самий стек, що в лабораторних 1–2. |
| Справжній AR | **WebXR Device API** (`immersive-ar`, `hit-test`, `dom-overlay`, `plane-detection`) | Безкоштовний стандарт браузера. У Chrome на Android працює поверх **ARCore**, тобто дає ті самі можливості, що нативний ARCore-застосунок із прикладу (площини, hit-test), але без APK. |
| 3D-графіка | **three.js** | Найпоширеніша безкоштовна 3D-бібліотека для WebGL; має вбудовану підтримку WebXR. Роздається з `node_modules`, без CDN. |
| Симулятор | Власний, на three.js | Справжній AR потребує телефона з ARCore. Симулятор дає змогу розробляти, тестувати й демонструвати на звичайному комп’ютері, а відомі розміри кімнати — перевіряти точність. |
| Сервер і БД | Node.js + Express, SQLite (`node:sqlite`) | Як у попередніх роботах. Довжину й площу сервер перераховує сам (тими самими функціями, що й клієнт), а не довіряє клієнту. |

**Альтернативи:**
- **Нативний Android + ARCore** (як у прикладі із завдання) потребує Android Studio, збирання APK і телефона для будь-якої перевірки.
- **AR.js** працює з паперовими маркерами, а не з довільними поверхнями: для вимірювання стін і підлоги не підходить.
- **Unity AR Foundation** — важке середовище; для веб-демонстрації та тестів незручне.
- **Google Cloud Vision API** розпізнає вміст зображень, але не будує 3D-площини й не дає метричних координат.

## Як симулятор відтворює ARCore

| Поведінка ARCore | У симуляторі |
|---|---|
| Площини знаходяться не одразу, а поки камера їх оглядає | «Впевненість» у поверхні накопичується з кожним кадром. Швидкість залежить від освітлення, відстані (до 5 м) і кута огляду. Поверхню знайдено, коли впевненість досягла 1 (~1–1,5 с при нормальному світлі). |
| Знайдена площина розростається | Сітка розширюється від місця, де поверхню знайшли, у бік ділянок, які оглядає камера. |
| Hit-test працює лише по знайдених ділянках | Промінь від прицілу (або місця кліку) перетинає лише знайдені ділянки; інакше — підказка, що зробити. |
| Однотонні поверхні (стеля) не розпізнаються | Стеля позначена як поверхня без деталей. |
| У темряві трекінг зупиняється | При «темно» поверхні не знаходяться, а hit-test повертає «Замало світла». |
| Точність кількох мм … см | До точки додається похибка вздовж площини (нормальний розподіл). Середньоквадратичне відхилення 2 мм × (1 + відстань/2) при нормальному світлі, 6 мм — при тьмяному. |

## Архітектура

```
public/js/geometry.js      відстані, ламана, площа (метод Ньюела), перевірка площинності, формат
public/js/measurement.js   поточний вимір: точки, порядок, замкненість, скасування
public/js/layer.js         3D-відображення: точки, лінії, підписи, прев’ю, приціл
public/js/sim/room.js      віртуальна кімната, процедурні текстури, сітка площин (шейдер)
public/js/sim/tracking.js  модель трекінгу: швидкість знаходження, похибка, еталони
public/js/sim/simulator.js камера, керування, трекінг, hit-test
public/js/xr/webxr.js      справжній AR через WebXR (hit-test, площини, dom-overlay)
public/js/app.js           інтерфейс: меню, збереження, перевірка точності
src/                       REST API (Express) та SQLite
test/                      модульні тести, test/e2e — браузерні перевірки
```

REST API: `GET /api/measurements`, `GET /api/measurements/:id`, `POST /api/measurements`, `DELETE /api/measurements/:id`.

## Справжній AR на телефоні

Потрібні Android-телефон із підтримкою ARCore («Google Play Services for AR») і Chrome. WebXR працює лише в захищеному контексті (HTTPS або `localhost`). Найпростіше підключити телефон через USB:

```bash
adb reverse tcp:3002 tcp:3002   # телефон відкриває http://localhost:3002, який веде на комп’ютер
```

Далі відкрийте на телефоні `http://localhost:3002` → «Почати AR» → наведіть камеру на підлогу чи стіну → торкайтеся екрана, щоб ставити точки.

> ⚠️ Режим WebXR написаний за специфікацією, але **не перевірявся на реальному телефоні**: під час розробки AR-пристрою не було. Усі функції перевірено в симуляторі.

## Тестування

- `npm test` — 15 модульних тестів:
  - геометрія: відстані, площі в різних площинах і неопуклих контурів, площинність, прилипання, формат;
  - вимір: додавання, повтори, порядок, скасування, ліміти;
  - модель трекінгу: залежність від світла, відстані, кута; відтворюваний генератор похибки;
  - REST API.
- `npm run test:e2e` — 23 браузерні перевірки симулятора:
  - пошук поверхонь;
  - висота дверей 210 см;
  - точність з похибкою трекінгу (> 99 % при нормальному і тьмяному світлі);
  - контур стільниці з площею 0,84 м²;
  - стеля й темрява;
  - клік мишею;
  - меню, одиниці, збереження й відкриття з бази;
  - діалог точності;
  - прилипання (до першої, проміжної й останньої точки, вимкнене прилипання) і видалення останньої точки.

## Обмеження

- Справжній AR — лише Android + Chrome із ARCore (iPhone Safari не підтримує WebXR AR).
- Точність реального ARCore — кілька міліметрів … сантиметрів; гірша в темряві, на однотонних і блискучих поверхнях.
- Симулятор відтворює поведінку трекінгу спрощено (див. таблицю вище).
