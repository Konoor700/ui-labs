# Лабораторна робота №2. Жестовий інтерфейс для управління базою даних

Вебзастосунок, у якому базою даних працівників можна керувати жестами руки перед вебкамерою: переглядати, додавати, змінювати й видаляти записи. Жести розпізнаються локально в браузері за допомогою **Google MediaPipe**. Відео нікуди не надсилається, платити нічого не потрібно.

## Запуск

Потрібні Node.js 22.13 або новіший, браузер Chrome чи Edge і вебкамера.

```bash
npm install      # також завантажує модель жестів (~8 МБ) у public/models
npm start        # http://localhost:3001
npm test         # модульні тести
npm run test:e2e # браузерні перевірки (Chrome без вікна й без звуку)
```

Відкрийте http://localhost:3001 і дозвольте доступ до камери. Сядьте так, щоб рука з долонею до камери була в кадрі на відстані 40–80 см.

Змінні середовища (необов’язкові): `PORT` (за замовчуванням 3001), `DB_FILE` (за замовчуванням `data/employees.db`).

## Жести

| Жест | Дія | Як показати |
|---|---|---|
| V-жест, утримати ~0,6 с | **Показати всіх** (оновити список) | Вказівний і середній пальці вгору |
| Кулак, потім вказівний палець | **Додати** працівника (відкриває форму) | Стиснути кулак на ~0,3 с, потім підняти вказівний палець |
| Коло вказівним пальцем | **Редагувати** вибраний запис | Вказівний палець угору, описати коло (достатньо ¾ оберту, можна овал) |
| Мах долонею вбік | **Видалити** вибраний запис (з підтвердженням) | Відкрита долоня, швидкий рух уліво або вправо |
| Рух долонею | Курсор на екрані | Курсор іде за центром долоні |
| Затримка курсора ~0,9 с | **Клік** у формах і вікнах, вибір рядка таблиці | Навести курсор і потримати руку: кільце на курсорі заповнюється |
| Щипок («OK») | **Миттєвий клік** будь-де | Зімкнути великий і вказівний пальці, інші пальці розігнуті |
| Великий палець угору, утримати ~0,6 с | **Зберегти** форму / **Так** у підтвердженні | Великий палець угору (кільце заповнюється на курсорі) |
| Великий палець униз, утримати ~0,6 с | **Скасувати** / **Ні** | Великий палець униз |

Утримання статичних жестів переживає короткі (до 0,3 с) «провали» розпізнавання, тому відлік не обривається, якщо модель на мить втратила позу.

**Типовий сценарій:**
1. Наведіть курсор долонею на рядок і потримайте — запис вибрано.
2. Опишіть коло пальцем — відкриється форма редагування.
3. Змініть дані, наводячи курсор на кнопки. Для імені й прізвища є швидкий вибір, для посади й зарплати — готові варіанти, для зарплати ще кнопки «±1000 / ±5000».
4. Утримайте «палець угору» — дані збережено, рядок у таблиці оновиться й підсвітиться.

**Введення даних у формі**, від найлегшого до найгнучкішого:
- кнопки швидкого вибору імені, прізвища, посади та зарплати;
- — надиктувати ім’я чи посаду голосом (гібридний інтерфейс, Web Speech API, як у лабораторній №1);
- «Клавіатура» — віртуальна клавіатура з великими клавішами, відкривається лише за потреби.

**Без камери** усе можна робити мишею. Картки жестів на екрані натискаються й імітують відповідний жест.

### Додатково

- **Пауза жестів.** Кнопка у шапці тимчасово вимикає розпізнавання.
- **«Клік затримкою курсора».** Перемикач у шапці. Якщо він заважає, клікати можна лише щипком.
- **Перевірка точності.** Система по черзі просить показати кожен жест (3, 5 або 10 спроб) і рахує влучання, помилки, пропуски й середній час розпізнавання. Результат можна скопіювати таблицею Markdown, наприклад для звіту. Дії з базою під час перевірки не виконуються.
- **Індикатори.** Показуються FPS, час обробки кадру й освітлення (попередження, якщо темно або пересвічено).

## Обґрунтування вибору технологій

| Компонент | Вибір | Чому |
|---|---|---|
| Тип застосунку | **Веб** | Працює на будь-якій ОС без встановлення. Браузер має доступ до камери (MediaStream API) і GPU (WebGL). |
| Розпізнавання рук | **MediaPipe Gesture Recognizer** (`@mediapipe/tasks-vision`) | Безкоштовний і з відкритим кодом. Працює локально (WebAssembly + GPU) у реальному часі (~30 FPS). Визначає 21 точку руки і 7 готових жестів (кулак, долоня, вказівний палець, «палець угору», «палець униз», V-жест, «I love you»). Відео не залишає комп’ютер, ключі API не потрібні. |
| Альтернативи | Google Cloud Video Intelligence API, OpenCV, Handtrack.js | **Video Intelligence** аналізує записане відео в хмарі із затримкою в секунди, тому не підходить для керування в реальному часі. Має лише обмежений безкоштовний ліміт і потребує ключа. **OpenCV** потребує власних моделей для рук. **Handtrack.js** визначає лише рамку руки, без пальців. |
| Рухові жести | **Власний рушій правил** (`public/js/gestures.js`) | Мах, коло й послідовність «кулак → палець» визначаються за траєкторією точок руки. Такі правила прозорі, легко налаштовуються і покриті тестами. |
| Сервер | **Node.js + Express** | Мінімальний REST API. Також сервер роздає бібліотеку MediaPipe і модель локально, без CDN. |
| База даних | **SQLite** (`node:sqlite`) | Уся база в одному файлі, без окремого сервера БД. |
| Доступ до БД | Прямий SQL, параметризовані запити | Запитів кілька, ORM зайвий. Параметризація захищає від SQL-ін’єкцій. |

## Архітектура

```
Браузер                                                       Сервер (Node.js)
┌────────────────────────────────────────────────────┐       ┌───────────────────────────────┐
│ Камера (getUserMedia, 640×480, 30 FPS)             │       │ GET    /api/employees         │
│   → MediaPipe GestureRecognizer (WASM + GPU)       │       │ POST   /api/employees         │
│       21 точка руки + статична поза                │ REST  │ PUT    /api/employees/:id     │
│   → GestureEngine (gestures.js)                    │ ◄───► │ DELETE /api/employees/:id     │
│       махи, коло, кулак→палець, щипок, утримання   │ JSON  │   validation.js → db.js       │
│   → команди, курсор, клік → таблиця, форми         │       │ /vendor/mediapipe, /models    │
└────────────────────────────────────────────────────┘       └───────────────────────────────┘
```

**Обробка кадру:**
1. Камера → MediaPipe: 21 точка руки й назва пози з упевненістю.
2. Рушій жестів визначає позу. Якщо модель не впевнена (менше 55 %), поза визначається за власними правилами: розігнуті й зігнуті пальці рахуються за відстанями до зап’ястка.
3. Рушій зберігає траєкторії руху долоні (0,5 с) та кінчика вказівного пальця (2,5 с) і розпізнає за ними рухові жести:
   - **мах** — велике горизонтальне зміщення за короткий час;
   - **коло** — сумарний кут повороту навколо центру траєкторії не менше 270°, радіус більш-менш сталий.
4. Статичні жести (V-жест, палець угору / униз) треба утримувати. Короткі провали розпізнавання відлік не скидають.
5. Події від рушія (команда, клік, підтвердження) виконують дію в інтерфейсі, а дія звертається до REST API.

**Захист від випадкових спрацювань:**
- пауза 1 с після кожної команди;
- статичні жести V-жест і «палець угору / униз» треба утримувати (кільце прогресу на екрані й на курсорі);
- мах угору свідомо не використовується: він спрацьовував би щоразу, коли людина просто піднімає руку;
- видалення лише з підтвердженням;
- у формі команди-махи вимкнені, працюють лише курсор, щипок і «палець угору / униз»;
- щипок не спрацьовує, коли рука стиснута в кулак.

### Структура проєкту

```
server.js                 запуск сервера
src/app.js                REST API, роздача статичних файлів і MediaPipe
src/db.js                 SQLite: схема, початкові дані, запити
src/validation.js         перевірка даних працівника
public/index.html         інтерфейс
public/style.css          стилі (світла й темна теми, адаптивна верстка)
public/js/camera.js       камера + MediaPipe, малювання «скелета» руки, FPS, освітлення
public/js/gestures.js     рушій жестів (без залежності від браузера)
public/js/app.js          таблиця, курсор, обробка подій, журнал
public/js/forms.js        форма з віртуальною клавіатурою, підтвердження видалення
public/js/accuracy.js     режим перевірки точності
public/models/            модель gesture_recognizer.task
scripts/download-model.js завантаження моделі
test/                     модульні тести
```

## Безпека

- Параметризовані SQL-запити, валідація на сервері: ім’я та прізвище з літер (2–80 символів), посада (2–60), зарплата — ціле число від 0 до 10 000 000.
- Тіло запиту до 4 КБ, зрозумілі повідомлення про помилки.
- Видалення лише після явного підтвердження «палець угору».
- Ключів API немає, відео обробляється локально.
- Дані виводяться в сторінку через `textContent` (захист від XSS).

## Тестування

**Модульні тести** (`npm test`, 21 тест):
- рушій жестів на синтетичних траєкторіях руки (30 FPS): кожен жест спрацьовує (зокрема недбале коло — овал на ¾ оберту), а схожі рухи — ні (повільний рух, пів кола, рух по прямій, мах кулаком, мах угору, палець без кулака, пізній палець після кулака);
- режими (у формі махи вимкнені, на паузі жести ігноруються), утримання статичних жестів зі «збоями» розпізнавання, щипок, дзеркальний курсор;
- REST API: CRUD, валідація, неіснуючі записи, некоректний JSON, роздача MediaPipe і моделі.

**Перевірки в браузері** (Chrome headless):
- **Справжня модель на офіційних тестових фото Google.** Розпізнано Thumb_Up (75 %), Closed_Fist (90 %), Pointing_Up (83 %) і Victory (78 %). Власні правила пози правильно визначили кулак і вказівний палець на справжніх руках.
- **Повний ланцюжок «камера → модель → інтерфейс»** (фото як вхід камери): 29–30 FPS, поза «палець угору» відображається в інтерфейсі.
- **Сценарії інтерфейсу.** V-жест «показати всіх», вибір рядка затримкою курсора і щипком, редагування колом зі збереженням через «палець угору» (зокрема зі «збоями» розпізнавання), видалення махом зі скасуванням (палець униз) і з підтвердженням затримкою на «Так», додавання через «кулак → палець» зі швидким вибором імені та клавіатурою, валідація, пауза, режим перевірки точності.

Точність на живій руці в різних умовах (освітлення, швидкість рухів) вимірюється вбудованим режимом «Перевірка точності».

## Можливі розширення

- Гібридний інтерфейс: поєднання з голосовим керуванням із лабораторної №1 (голос для введення імен, жести для навігації).
- Власний класифікатор жестів (MediaPipe Model Maker) для додаткових статичних жестів.
- Розгортання на GitHub Pages (клієнт) + будь-який Node-хостинг (API). Для доступу до камери потрібен HTTPS.
